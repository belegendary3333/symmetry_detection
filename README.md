# 镜像对称轴检测

## 1.算法概述
本算法旨在实现图像镜像对称轴的自动检测。其核心思想是将视觉对称问题转化为数学参数估计问题，通过 **SIFT 特征提取**、**对称点对几何参数化** 以及 **极坐标空间聚类** 三个阶段实现对称轴的精准定位 。

## 2.数学逻辑与实现方法
### 2.1 特征提取与匹配

算法利用 SIFT 算子提取图像的局部梯度特征 。

-   **镜像处理**：将原图进行水平翻转得到 `reflected_image`。
    
-   **距离度量**：在原图和镜像图中寻找特征点，计算其描述符之间的欧氏距离 $D(d1, d2)$ 。
    
-   **Lowe's Ratio Test**：通过筛选满足 $\frac{D(m1)}{D(m2)} < 0.75$ 的点对来剔除误匹配，确保匹配的可靠性。
    

### 2.2 几何参数化（极坐标转化）

对于匹配点对 $pt1$ 和 $pt2$，其对称轴被定义为两点连线的中垂线 。

-   **中点计算**：$(x_c, y_c) = (\frac{x1+x2}{2}, \frac{y1+y2}{2})$ 。
    
-   **方向角估计**：$\theta = \arctan2(y2-y1, x2' - x1)$ 。
    
-   **参数转化**：利用直线极坐标方程 $r = x_c \cos\theta + y_c \sin\theta$ 将对称轴映射为参数空间中的一个点 $(r, \theta)$ 。
    

### 2.3 统计聚类与决策

算法采用 **六边形网格 (Hexbin)** 对参数空间进行密度统计 。

-   **聚类原理**：真实对称轴对应于参数空间中样本最密集的区域 。
    
-   **结果筛选**：通过 `sort_hexbin_by_votes` 函数对网格计数降序排列，取票数最高（众数）的参数作为最终对称轴。

## 3. 代码结构说明

### 核心模块：`mirror_symmetry.py`

**功能描述**

`Mirror_symmetry_detection`：封装检测逻辑的类。包含 SIFT 初始化、图像翻转及特征点维护。

`find_matchpoints()`：执行 KNN 匹配并应用 Lowe's ratio 测试。

`find_point_r_theta()`：将匹配点对转化为极坐标参数 $r$ 和 $\theta$。

`draw_hex()`：可视化参数空间的六边形分布图。

`draw_mirrorLine()`：在原图上绘制检测到的对称轴（红色直线）。

### 测试入口：`detect.py`

-   **`example` 模式**：运行特定的蝴蝶案例，并开启 `show_detail` 以展示特征匹配和六边形聚类细节。
    
-   **`test` 模式**：批量测试动物、建筑、倒影、阴影及旋转对称等多种场景下的图像。
  ## 4. 实验结果分析

-   **简单场景**：在无背景干扰（如蝴蝶、剪纸）下，匹配准确率超过 90%，误差控制在 2px 以内 。
    
-   **复杂场景**：对于含轻微阴影或人脸的场景表现稳定 。
    
-   **失效案例**：在多对称轴场景下，因算法仅选取单一最高峰值，会导致“漏检”；在非对称图像中，局部重复纹理会诱发“伪对称轴” 。
## 5. 局限性与改进方向

### 5.1 主要局限

1.  **亮度鲁棒性**：当物体与其倒影存在强对比差异时，特征匹配率会显著下降 。
    
2.  **多目标检测**：目前仅支持检测单一最显著对称轴 。
    
3.  **低纹理失效**：在纯色或光滑物体表面，SIFT 提取的特征点不足以支撑统计聚类 。
    

### 5.2 建议改进

-   **融合算法**：引入 ORB 或 SURF 增强对光照变化的鲁棒性 。
    
-   **多峰值检测**：采用密度峰值聚类 (DPC) 自动识别图像中的多个对称轴 。
    
-   **预处理优化**：通过自适应直方图均衡化减少环境光干扰 。
